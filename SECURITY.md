# Security policy

## Reporting a vulnerability

Please use GitHub's private reporting: the **Security** tab of this repository, then **Report a vulnerability**. Do not open a public issue.

Include the steps to reproduce and what an attacker could do. You will get an answer within 7 days.

## Scope

The latest version on `master` and the site it deploys. The site holds personal data of real applicants, so please test against your own copy. Do not access, change or delete data that is not yours, and do not run denial of service tests.

The README lists the known limits of the current design.
